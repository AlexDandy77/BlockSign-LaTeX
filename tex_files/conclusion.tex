\chapter*{CONCLUSIONS}

The work carried out in this project demonstrates that secure, scalable, and verifiable document management can be achieved through the careful integration of modern cryptographic techniques, structured workflows, and practical user interfaces. By replacing traditional password-based authentication with Ed25519 key pairs and challenge–response mechanisms, the system eliminates a major vulnerability of centralized platforms while improving usability and security.

The design of the registration process, supported by email-based verification and administrative approval, ensures that only legitimate users gain access to the platform. At the same time, the introduction of digital signatures over canonical payloads provides a strong guarantee of document integrity and participant accountability. Each document is uniquely identified by its cryptographic hash, which allows all stakeholders to independently verify its authenticity.

From a functional perspective, the project delivers a complete document signing platform with user registration, passwordless authentication, document creation with multi-participant workflows, and comprehensive signature collection. The system supports three distinct deployment environments: a web application built with Next.js and React, a native iOS mobile application developed with SwiftUI, and a robust back-end API implemented in Node.js with Express and PostgreSQL. Email notifications powered by Amazon SES keep participants informed throughout the signing process, while document storage on Amazon S3 ensures durability and scalability. The platform includes blockchain anchoring on Polygon network, providing immutable proof of document existence and timestamping for transparency and legal validity.

The implementation confirms the feasibility of using modern cryptographic libraries and structured database schemas to create secure document workflows with enterprise-grade infrastructure. The system operates in production on AWS infrastructure, with EC2 instances handling backend computing, Elastic IP ensuring stable connectivity, and comprehensive DevOps practices including automated CI/CD through GitHub Actions and mobile deployment via Xcode Cloud. The iOS application leverages native biometric authentication through Face ID and Touch ID, providing seamless security that matches user expectations for mobile applications.

In conclusion, this project achieves its objective of creating a production-ready system for passwordless user authentication and legally binding document signing. It demonstrates the successful combination of cryptographic security with intuitive user workflows across multiple platforms, establishing a complete solution that addresses real-world document management needs. The platform integrates modern cloud infrastructure, blockchain technology, and mobile-first design principles to deliver a secure, accessible, and verifiable document signing experience suitable for organizational deployment.
